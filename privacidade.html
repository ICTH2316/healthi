Política de Privacidade

O Healthi é um aplicativo pessoal, de uso privado, que não é oferecido ao público.

Dados acessados

Com autorização explícita do próprio usuário pelo Google, o Healthi lê dados de saúde e atividade física da conta Google desse usuário (por exemplo: sono, frequência cardíaca, passos e exercícios) e pode registrar nela os treinos feitos no aplicativo.

Uso dos dados

Os dados são usados apenas para mostrar ao próprio usuário informações e recomendações sobre sua saúde e seus treinos.

Armazenamento e compartilhamento

  • Os dados ficam armazenados no equipamento do próprio usuário.
  • Os dados não são vendidos, não são usados para publicidade e não são compartilhados com terceiros.
  • O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
